# E_Comm-Website
🛍️ Shopify E-Commerce Website
This is an E-Commerce website built with a frontend using HTML, CSS, JavaScript, and a backend powered by Java (Spring Boot). The backend uses MySQL as the database, and Postman is used for API testing. The site allows users to view products, add them to their cart, and make purchases. It includes features like product listing, shopping cart functionality, and user authentication.

🛠️ Technologies Used : 
Frontend: HTML, CSS, JavaScript, Bootstrap
Backend: Java (Spring Boot)
Database: MySQL
API Testing: Postman


🧩 Prerequisites : 
Java 11 or later
Spring Boot
MySQL
Postman
Maven (for backend dependency management)


⚙️ Backend Setup (Spring Boot)
Navigate to the backend directory ---> Install dependencies & build the project ---> Run the Spring Boot application 
The backend server will start on: http://localhost:8080


📦 Dependencies
Backend: Spring Boot Web , Spring Boot DevTools , Spring Data JPA , MySQL
Frontend:Bootstrap
